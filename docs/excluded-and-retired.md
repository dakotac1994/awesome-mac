# Excluded & Retired

Apps we checked during research (2026-10-06) and deliberately left out, with reasons. This log keeps the list honest: a missing app isn't an oversight — it was considered.

## Discontinued (dead projects)

| App | What it was | Why excluded |
|---|---|---|
| **Fig** | Terminal autocomplete from Amazon | Discontinued after Amazon's acquisition (shut down 2023). |
| **Authy Desktop** | Desktop 2FA app by Twilio | Discontinued by Twilio (March 2024). |
| **Tweetbot** | Third-party Twitter client | Discontinued after Twitter/X revoked third-party API access (January 2023). |
| **Twitterrific** | Third-party Twitter client | Discontinued after Twitter/X revoked third-party API access (January 2023). |
| **Wunderlist** | Task manager | Shut down by Microsoft (2020); users migrated to Microsoft To Do. |
| **Mailbox** | Email client by Dropbox | Discontinued by Dropbox (2016). |

## Deliberate scope notes

- Web-only services with no Mac client are out of scope, however good they are.
- Apps that are iOS-only, Windows ports, or malware-flagged don't belong here.
- Paid apps are welcome (this is not an OSS-only list) — but subscriptions with no real free tier and perpetual-license options are tagged honestly, not punished.
