# Categories

The eleven categories this list organizes macOS apps into, and what's in scope for each.

| Category | Scope |
|---|---|
| **Productivity** | Launchers, task managers, calendars, email clients — apps that run your day. |
| **Developer tools** | Editors, IDEs, database clients, API tools, diff viewers, proxies. CLI-only dev tools generally live here only when macOS is their home. |
| **Utilities & menu-bar tools** | Menu-bar organizers, clipboard managers, automation (Keyboard Maestro, Hazel), screenshot tools, archivers. The catch-all for "makes macOS better" apps. |
| **Window management** | Snapping, tiling, and workspace tools — Rectangle through yabai. |
| **Media & design** | Image and video editors, screen recorders, media players, converters, design tools. |
| **Security & privacy** | Password managers, firewalls, malware scanners, ad blockers, privacy monitors. |
| **AI-powered apps** | AI chat clients, local-model tools, AI writing and transcription assistants — with real Mac apps, not web-only services. |
| **File management** | Alternative file managers, FTP/SFTP/cloud clients, file search and preview utilities. |
| **Terminal & shell enhancements** | Terminal emulators, shells, prompts, multiplexers, and the terminal-side tooling that makes the shell pleasant. |
| **System & performance** | Menu-bar system monitors, disk cleaners, fan/battery tools, uninstallers. |
| **Note-taking & writing** | Notes apps, markdown editors, writing environments, journals. |

## Deliberate scope notes

- This list covers **all license types** — open-source, free, freemium, paid, and subscription — each tagged with its pricing model. For an OSS-only macOS list, see [awesome-oss-macos](https://github.com/Awesome-llms-labs/awesome-oss-macos).
- Web-only services with no Mac client are out of scope, however good they are.
- Discontinued apps are excluded and logged in [excluded-and-retired.md](excluded-and-retired.md).
